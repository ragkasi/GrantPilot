# GrantPilot Demo Assets

Sample documents for use during live demos. Upload these to a GrantPilot project
to trigger the **real AI analysis pipeline** (requires `ANTHROPIC_API_KEY`).

## Files

| File | Document Type | Upload as |
|------|--------------|-----------|
| `sample-grant-opportunity.txt` | Grant RFP | Grant Opportunity Document |
| `sample-mission-statement.txt` | Nonprofit profile | Mission Statement |
| `sample-program-description.txt` | Program details | Program Description |

## Demo Flow

1. Log in and create a new project (grant name: "Community STEM Access Fund")
2. Upload `sample-grant-opportunity.txt` as **Grant Opportunity Document**
3. Upload `sample-mission-statement.txt` as **Mission Statement**
4. Upload `sample-program-description.txt` as **Program Description**
5. Click **Run Analysis**
6. With `ANTHROPIC_API_KEY` set, the real pipeline runs — results are grounded in these docs

## Notes

- All content is fictional and clearly labeled as sample data
- The nonprofit ("Horizon Youth Collective") and the grant ("Community STEM Access Fund")
  are both invented for demo purposes
- Do not use these documents for real grant applications
